# Natas Writeups

[OverTheWire Natas](https://overthewire.org/wargames/natas/) 워게임 풀이 모음입니다.
웹 보안 공부하면서 각 레벨을 Python으로 풀어본 코드들입니다.

## 파일

- `natas8.py` — 인코딩 역추적 (hex / reverse / base64)
- `natas9.py` — 커맨드 인젝션
- `natas10.py` — 정규식 필터 우회 커맨드 인젝션

## 실행

```bash
pip install requests
python natas8.py
```

비밀번호 부분은 본인 값으로 바꿔서 실행하세요.
